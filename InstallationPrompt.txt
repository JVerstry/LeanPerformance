You are installing LeanPerf, a skill that audits a Lean project's build time
and recommends concrete, prioritized ways to speed it up. Follow these steps.
This installs one small text file (a skill) — no software, no dependency, and
nothing in the Lean project's build is changed.

======================================================================
1. Check your assistant supports skills
======================================================================

A skill is a folder holding a SKILL.md file that the assistant loads on demand.
Claude Code supports them natively. If you are a different assistant, use its
equivalent mechanism (custom command, rule or instruction file) if it has one.
If it has none, stop and tell the user to paste the contents of
LeanPerformanceAudit.txt (same repository) as a prompt instead — that works
with any assistant.

======================================================================
2. Ask where to install it
======================================================================

Ask the user which they want, and wait for the answer:

- User-level: available in every project, adds nothing to any project's
  repository. Claude Code folder: ~/.claude/skills/leanperf/
  (on Windows: %USERPROFILE%\.claude\skills\leanperf\).
- Project-level: only for the current Lean project, can be shared with
  collaborators through git. Claude Code folder: .claude/skills/leanperf/
  at the project root.

If a leanperf folder already exists there, tell the user and ask whether to
replace it before overwriting anything.

======================================================================
3. Create the skill
======================================================================

Create the folder chosen above and, inside it, a file named SKILL.md with
exactly this content (everything between the two lines of equals signs):

==========
---
name: leanperf
description: Audit a Lean/Lake project's build time and recommend prioritized fixes. Use when the user types /leanperf or asks to audit, profile or speed up the build of a Lean project.
---

# /leanperf — audit a Lean project's build time

The audit instructions are maintained in the LeanPerformance repository, so they
stay current:

https://raw.githubusercontent.com/JVerstry/LeanPerformance/main/LeanPerformanceAudit.txt

1. Fetch that file in full and read all of it.
2. Carry out the audit it describes on the Lean project in the current
   directory, following its instructions exactly.
3. If the file cannot be fetched (no network, blocked), say so in one sentence
   and ask the user to paste the contents of LeanPerformanceAudit.txt instead.
   Do not audit from memory.
4. Report first. Do not modify the user's files, or run a change the audit
   recommends, until the user says to go ahead.
==========

======================================================================
4. Tell the user what you did
======================================================================

Reply with a short summary:
- the exact path of the SKILL.md you created;
- how to use it: type /leanperf inside their Lean project, or ask the assistant
  to audit the project's build time (some assistants need a restart or a new
  session before a new skill shows up);
- that the skill fetches the audit text from
  github.com/JVerstry/LeanPerformance each time it runs, so it needs network
  access and always uses the latest version of the audit.
